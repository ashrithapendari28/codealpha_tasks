  # 2BHK Residential House Plan in AutoCAD

This project presents the **design and drafting of a 2BHK residential house plan using AutoCAD**. The layout is designed to provide a comfortable, functional, and well-organized living space suitable for a small family.

The house plan includes **two bedrooms, a living room, kitchen, dining area, bathrooms, and other essential spaces**. Proper attention is given to room arrangement, dimensions, accessibility, ventilation, and efficient utilization of available space.

## Project Features

* 2BHK residential floor plan
* Two bedrooms with suitable space allocation
* Living and dining areas
* Kitchen with functional layout
* Bathroom/toilet arrangement
* Doors and windows positioned for accessibility and ventilation
* Accurate dimensions and annotations
* Clean architectural drafting using AutoCAD

## Objective

The objective of this project is to develop a practical **2BHK residential floor plan** while gaining experience in architectural drafting, space planning, dimensioning, and AutoCAD drawing techniques.

## Software Used

* **AutoCAD**

This project is suitable for **civil engineering students, architecture students, CAD learners, and beginners** interested in residential building design and architectural drafting.

# Flanged Coupling Design in AutoCAD

This project presents the **design and drafting of a Flanged Coupling using AutoCAD**. A flanged coupling is a mechanical component used to connect two shafts and transmit torque and rotational motion between them.

The model was created using standard AutoCAD drafting and modeling techniques, with attention to accurate dimensions and engineering drawing conventions. The project includes the major components of a flanged coupling, such as **flanges, shafts, bolt holes, bolts, and keyways**.

## Project Features

* 2D engineering drawing of a flanged coupling
* Front, top, and side views
* Sectional view for representing internal features
* Accurate dimensioning and annotations
* Center lines and hidden lines
* Standard mechanical drawing practices

## Objective

The main objective of this project is to develop practical skills in **AutoCAD mechanical drafting, dimensioning, sectional views, and component design** while creating a detailed representation of a commonly used mechanical power-transmission component.

## Software Used

* **AutoCAD**

This project is suitable for **mechanical engineering students, CAD learners, and beginners** looking to practice mechanical component drafting in AutoCAD.
